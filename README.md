## Development

This project is built using:
- [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/) for styling
- Hosted on [Vercel](https://vercel.com/)

To run the project locally:
```bash
npm install
npm run dev
```
